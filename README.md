# Menti — 팀 CREAM 멘토링 결과보고

행복한경영대학 미니 프로젝트 팀 CREAM의 멘토링 결과를 공개형 웹 리포트로 정리한 프로젝트입니다. `문제 → 멘토의 연결 → 실행 → 결과`의 흐름 안에서 접점 3개가 결과 6개로 이어진 과정을 보여 줍니다.

- 공개 사이트: <https://cafeilboon-hub.github.io/menti/>
- 현재 배포 파일: `index.html`
- 공개 콘텐츠 원고: [`docs/CONTENT.md`](docs/CONTENT.md)
- 제품·디자인 기준: [`docs/PRODUCT.md`](docs/PRODUCT.md)
- 현황과 보강 후보: [`docs/SITE_REVIEW.md`](docs/SITE_REVIEW.md)
- 기존 기획 자료와의 연결: [`docs/SOURCE_MAP.md`](docs/SOURCE_MAP.md)

## 로컬에서 보기

Python 3가 설치되어 있다면 저장소 루트에서 다음 명령을 실행합니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:4173/>을 엽니다.

## 구성과 조작

- 상단의 `문제`·`멘토의 연결`·`실행`·`결과` 장 탐색
- 우측의 `다음 내용` 버튼으로 `첫 화면 → 01 → 02 → 03 → AI 동영상 제작 → 04 → Before/After → What we learned → 첫 화면` 순환, 마지막에는 `처음으로` 복귀
- 첫 화면의 경로 노드로 각 장에 직접 이동
- 각 장은 헤더를 제외한 화면 높이를 한 장으로 사용하며, 스크롤 스냅과 순차 진입 애니메이션으로 전환
- 장마다 페이드·슬라이드·줌인·줌아웃 조합을 달리하고, 약 1.6초의 여유 있는 전환과 iOS식 눌림·스프링 반응을 제공
- 기반·연결·실행·결과·전후 비교 표는 구리·오커·세이지·슬레이트 색상으로 역할과 상태를 구분
- URL 해시 `#overview`, `#problem`, `#connection`, `#execution`, `#video-solution`, `#results`, `#change`, `#lessons`
- AI 동영상 제작 화면에서 `프롬프트 → 장면 설계 → 이미지 생성 → 영상 연결 → MP4 출력` 흐름, 실제 제작 UI 3종과 결과 MP4 재생
- `motioncore.ai에서 보기` 버튼으로 제품 사이트 이동

## 현재 편집 구조

현재 사이트는 CSS, HTML, JavaScript가 하나의 `index.html`에 들어 있는 정적 페이지입니다. 별도 빌드 없이 GitHub Pages에서 서비스할 수 있습니다. 경로형 첫 화면, 고정 장 탐색, 화면 단위 장 전환, 색으로 구분한 결과 표, 모바일 세로형 전후 비교를 포함합니다. 모션 감소 설정을 사용하면 장 전환 애니메이션과 탭 반응을 거의 즉시 표시합니다.

공개 원고와 제품 기준은 Markdown으로 분리되어 있습니다. 카피를 바꿀 때는 `docs/CONTENT.md`와 공개 원칙을 먼저 확인하고, 화면 변경 후에는 `design-qa.md`와 `qa/`의 데스크톱·모바일 캡처를 함께 갱신합니다.

## 공개 전 확인 원칙

- 소개받은 인물은 본인 동의 전까지 직함으로만 표기합니다.
- 협업 3개사 사명은 공개하지 않습니다.
- 자체 제품 개발 성과를 멘토링 성과로 합산하지 않습니다.
- 수치·계약·협업 상태는 근거를 확인한 뒤 갱신합니다.

## 배포

현재 GitHub Pages는 저장소 루트의 `index.html`을 서비스합니다. 이 개편안은 먼저 로컬에서 검토하며, 승인 뒤 별도 변경 묶음으로 커밋·푸시합니다.
