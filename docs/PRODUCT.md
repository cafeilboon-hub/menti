# 제품·디자인 기준

## 독자

- **주 독자** — 투자자, 잠재 고객의 엔지니어링 리드, 기자. 모바일 또는 두 번째 모니터에서 링크를 열고 “이 회사가 실제로 무엇을 해냈는가”를 확인합니다.
- **부 독자** — 행복한경영대학 운영진과 동기 원우. 발표 후 세부 내용을 다시 확인합니다.

핵심 과업은 민성이 4개월 동안 실제로 무엇을 했는지 5분 안에 판단하는 것입니다.

## 목적

행복한경영대학 미니 프로젝트 팀 CREAM의 멘토링 결과를 기록하고, 멘토가 연결한 접점 3개가 결과 6개로 이어진 과정을 보여 줍니다. 동시에 민성의 제품과 실행 역량을 과장 없이 소개합니다.

발표덱은 현장 발표용이고, 웹사이트는 링크로 오래 남는 공개 자료입니다. 외부 독자가 내용을 신뢰하고 제품 데모나 미팅으로 이어지는 것이 장기적인 성공 기준입니다.

## 브랜드 성격

**정확한 · 단단한 · 담백한.**

계약이 없으면 없다고 쓰고, 근거 없는 수치는 넣지 않습니다. 물리적 대상으로 비유하면 에칭 라벨이 새겨진 알루미늄 패널에 가깝습니다. 매끈하지만 장식이 없고, 모든 표시가 기능을 가집니다.

## 디자인 원칙

1. **구조가 곧 은유다.** 접점 → 경로 → 결과라는 이야기와 노드 → 트레이스 → 연결이라는 오토라우터 구조를 같은 시각 언어로 사용합니다.
2. **엔지니어의 눈으로 읽힌다.** 배선은 배경 장식이 아니라 실제 정보 관계를 설명할 때만 씁니다.
3. **말하지 말고 보여 준다.** 자동 배선의 개념을 흐름과 인터랙션으로 전달합니다.
4. **없는 것은 없다고 쓴다.** 미확정 수치·계약을 만들지 않고, 공개 동의 전에는 직함만 사용합니다.
5. **한 화면에 한 생각.** 각 장은 하나의 주장과 그 주장을 뒷받침하는 정보만 담습니다.

## 피해야 할 표현

- 보라·파랑 그라디언트, 로봇 일러스트 등 전형적인 AI 회사 클리셰
- 의미 없이 깔린 회로 패턴
- 큰 숫자와 작은 라벨만 반복하는 SaaS식 스탯 행
- 동일한 카드 그리드의 기계적 반복
- 실제 순서가 없는 곳의 불필요한 번호 장식

## 접근성

- WCAG 2.1 AA 수준의 텍스트 대비를 유지합니다.
- `prefers-reduced-motion: reduce`에서는 콘텐츠가 즉시 완성 상태로 보이게 합니다.
- 색만으로 의미를 전달하지 않습니다.
- 키보드 탐색, 포커스 표시, 해시 기반 직접 이동을 유지합니다.
- 한글은 Pretendard → Malgun Gothic → Apple SD Gothic Neo 순의 시스템 폴백을 사용합니다.

## 공개 원칙

- 소개받은 인물은 동의 전까지 직함으로만 표기합니다.
- 협업 3개사 사명은 공개하지 않습니다.
- “멘토의 소개가 없었다면 이어졌는가?”가 아니오인 결과만 멘토링 성과로 집계합니다.
- 제품 개발 완료처럼 자체적으로 만든 성과는 포트폴리오 설명에만 사용합니다.
